# 포천 한일윌로모터펌프 - 파워펌프 서비스센터

포천시 지역 지하수 모터펌프, 배수펌프, 심정펌프, 압력탱크, 동파, 인버터 낙뢰 피해 출장수리 전문 웹사이트입니다.
가평/홍천/남양주/경기도광주/여주/이천/춘천과 색상·레이아웃·서비스 표현 방식을 전부 다르게 제작했습니다.

## 이 사이트만의 차별점

- **톤**: 올리브(olive) + 세이프티 앰버(safety amber). "야전교범/현장관리대장" 유틸리티 톤 — 다크 올리브 헤더·히어로, 해저드 스트라이프(대각선 안전줄무늬) 장식, 각진 코너(2~4px radius).
  (가평=네이비/골드·글래스, 홍천=딥그린/코랄·세리프, 남양주=차콜/오렌지·모노스페이스, 광주=코발트/테라코타·벤토그리드, 여주=버건디/골드·아이콘카드, 이천=모노크롬/레드·갤러리, 춘천=틸/피치·오가닉웨이브)
- **헤더**: 다크 올리브 고정 상단바 (플로팅 필/화이트 바와 구분).
- **히어로**: 점선 코너 브래킷 프레임(사격장 조준경/현장 사진대지 모티프) 안에 카피 배치.
- **증상 안내**: 신호등 상태등(빨강/앰버/초록 램프) 패널형 리스트 — 기존 진단위젯/체크리스트/조약돌/dl-list와 구분.
- **서비스 표현**: OP-01~04 코드가 붙은 필드카드, 오른쪽 상단 모서리를 잘라낸(clip-path) 배지 형태.
- **출장권역**: 매장 소재지(양평) 강조 없이 포천 자체 권역을 POCH-A~D 구역코드 + 계단식 인덴트 리스트로 안내.
- **작업사례**: 3건 (수중모터 마당 인양 / 배수펌프·배관 정비 / 심정펌프 인버터 제어반 점검) — 실사진 반영.
